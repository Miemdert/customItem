## 🇷🇺 Русский

🔧 Плагин для Minecraft серверов, который позволяет легко создавать предметы с кастомным лором, названием и зачарованиями.

### 📥 Установка

1. Скачайте последнюю версию из [Releases](https://github.com/Miemdert/customItem/releases)
2. Поместите `.jar` файл в папку `plugins/` вашего сервера
3. Перезапустите сервер

**Поддерживаемые ядра**: Paper, Spigot, Purpur (1.21.x)

### 🛠️ Функции

- ✨ Выбор кастомного имени, лора
- ✨ Выбор кастомного цвета
- ✨ Удобный выбор зачарований для предмета

## 🇬🇧 English

🔧 A Minecraft server plugin that makes it easy to create items with custom lore, names, and enchantments.

### 📥 Installation

1. Download the latest version from [Releases](https://github.com/Miemdert/customItem/releases)
2. Place the `.jar` file into your server's `plugins/` folder
3. Restart your server

**Supported servers**: Paper, Spigot, Purpur (1.21.x)

### 🛠️ Features

- ✨ Custom name and lore editor
- ✨ Custom color picker for item text
- ✨ Intuitive enchantment selection GUI
